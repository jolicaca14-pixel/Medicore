# MediCore Pro - System Overview 📘

## Architecture
The system is built as a highly optimized React PWA, using a role-based access control (RBAC) model to manage clinical and administrative workflows.

### Core Modules
- **Authentication**: Managed via the `useAuth` hook, integrating `sessionStorage` for secure session persistence during clinical sessions.
- **Clinical Management**: Specialized views for Professionals, ensuring data integrity (CIE-11, CUPS) and clinical safety (Antecedent verification).
- **Administrative/HR**: Role-based views for Admin and Secretary roles, including contract management and payroll calculations.
- **Interoperability**: Support for RDA (Resumen Digital de Atención) compliant with Resolution 1888 of 2025.

## Security Measures
1. **Input Sanitization**: All user-provided text is sanitized to prevent XSS.
2. **Session Persistence**: Sessions are isolated to `sessionStorage` and cleared explicitly on logout.
3. **Clinical Guardrails**: Mandatory validation for diagnoses and warnings for missing clinical antecedents.
4. **RBAC**: Strict separation of concerns between Admin, Professional, Secretary, and Diagnostic roles.

## Data Standards
- **ICD-11 (CIE-11)**: Diagnostic coding standard.
- **CUPS/SOAT**: Procedure and billing standards for the Colombian healthcare context.
